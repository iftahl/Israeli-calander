לוח ישראלי – גרסה 2

העלאה ל-GitHub Pages:
1. העלו את כל הקבצים והתיקיות שבתיקייה זו לשורש ה-Repository.
2. ודאו ש-index.html נמצא בשורש ושהקובץ data/calendar-data.json קיים.
3. Settings > Pages > Deploy from a branch > main > /(root).

עדכון עתידי:
עורכים רק את data/calendar-data.json דרך GitHub ולוחצים Commit changes.
שנו גם את meta.dataVersion ואת meta.lastUpdated כדי שיהיה קל לזהות שהנתונים התעדכנו.

מבנה חופשה:
{"start":"2027-09-01","end":"2027-09-03","name":"שם החופשה","groups":["kindergarten","elementary","middle","high"]}

מבנה אירוע בודד:
{"date":"2027-09-01","name":"שם האירוע","category":"official"}

קטגוריות: official, eve, observance, education, schoolNote
